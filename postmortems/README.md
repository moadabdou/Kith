# Postmortems

One file per phase (`phase-N.md`, half a page) + `chaos-log.md` for the
Phase 7 drills. Format:

- **What surprised me** — predictions that were wrong
- **What Discord did differently** — compare with the phase's reference post
- **What I'd do next time** — the lesson, compressed

Rule: a phase isn't done until its postmortem exists.
